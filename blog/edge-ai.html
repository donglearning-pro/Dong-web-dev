Edge AI & ML: Kẻ Săn Gian Lận và Bậc Thầy Điều Khiển Bằng Cử Chỉ

Hành trình đi qua hai thế giới: Từ việc nhào nặn hàng triệu dòng dữ liệu tài chính đến việc biến camera laptop thành đôi mắt thần kỳ nhận diện cử chỉ tay thời gian thực.

Trong thế giới Trí tuệ nhân tạo, chúng ta thường nghe về những cụm server khổng lồ chạy mô hình ngôn ngữ lớn. Nhưng "vẻ đẹp" thực sự đối với một maker lại là Edge AI — đưa trí tuệ thông minh xuống chạy cục bộ, trực tiếp trên máy tính cá nhân của mình. Trong bài viết này, tôi sẽ tổng kết lại hai dự án mang hai sắc thái hoàn toàn khác biệt mà tôi vừa chinh phục.

1. Kẻ Săn Dữ Liệu: Dự án Phát Hiện Gian Lận (Fraud Detection)

Dự án này thiên về Phân tích Dữ liệu và Bảo mật. Nó tập trung vào việc xử lý dữ liệu lớn, xây dựng mô hình Học máy (Machine Learning) để "ngửi" thấy mùi gian lận từ các tập dữ liệu thô và phân loại các giao dịch hoặc hành vi bất thường.

Quá trình rèn luyện mô hình

  • Làm sạch dữ liệu: Thu thập, xử lý các giá trị thiếu (missing values) và chuẩn hóa dữ liệu số để đưa về cùng một quy chuẩn.
  • Trị bệnh "Thiên vị": Giải quyết bài toán mất cân bằng dữ liệu (Imbalanced Data) — một thực tế đau đầu khi số ca gian lận luôn ít hơn hàng ngàn lần so với giao dịch hợp pháp.
  • Huấn luyện & Đánh giá: Thử nghiệm các mô hình phân loại hạng nặng như Logistic Regression, Random Forest, XGBoost. Không dùng Accuracy thông thường, tôi phải đánh giá bằng các chỉ số chuyên dụng và khắt khe hơn: Precision, Recall và F1-Score.

Khó khăn & Đánh đổi

Thử thách lớn nhất là nếu không xử lý kỹ dữ liệu nhiễu và cực kỳ lệch, mô hình sẽ bị "học vẹt" (Overfitting) và khôn lỏi chọn cách luôn đoán là "không gian lận" để đạt tỷ lệ đúng 99%. Bài toán đau đầu của người làm bảo mật là việc tinh chỉnh (tối ưu hóa) sao cho giảm tối đa tỷ lệ "bỏ sót gian lận" (False Negative) mà không làm khách hàng khó chịu vì bị "báo động nhầm" (False Positive).

Mở rộng bài toán cảnh báo: Thay vì dữ liệu số, tôi thử nghiệm AI phát hiện hành vi vật lý. Hệ thống nhận diện hành vi cầm điện thoại lên, ngay lập tức bật cảnh báo và chụp ảnh làm bằng chứng!

Source Code: AI Evidence Collector

Đoạn code dưới đây sử dụng mô hình YOLO11 để phát hiện vật thể và OpenCV để ghi hình. Tôi đã thêm thuật toán so sánh thời gian (logic cooldown 2 giây) để tránh việc camera chụp liên tục hàng trăm tấm ảnh gây đầy bộ nhớ.


import cv2
from ultralytics import YOLO
import winsound
import os
import time

# 1. Tạo thư mục 'canh_bao' nếu chưa có
if not os.path.exists('canh_bao'):
    os.makedirs('canh_bao')

model = YOLO('yolo11s.pt') 
cap = cv2.VideoCapture(0)

last_saved_time = 0  # Biến ghi lại lần cuối chụp ảnh

while cap.isOpened():
    success, frame = cap.read()
    if not success: break

    results = model(frame, conf=0.25, verbose=False) 
    found_phone = False

    for r in results:
        for box in r.boxes:
            name = model.names[int(box.cls[0])]
            if name in ['cell phone', 'remote']:
                found_phone = True
                break
    
    if found_phone:
        current_time = time.time()
        
        # Cảnh báo âm thanh và chữ
        winsound.Beep(1000, 200)
        cv2.putText(frame, "DA CHUP ANH BANG CHUNG!", (50, 80), 
                    cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 0, 255), 2)

        # 2. KIỂM TRA: Nếu cách lần chụp trước hơn 2 giây thì mới chụp tiếp
        if current_time - last_saved_time > 2:
            # Tạo tên file theo ngày giờ: ví dụ phone_17123456.jpg
            file_name = f"canh_bao/phone_{int(current_time)}.jpg"
            
            # Lệnh chụp và lưu ảnh
            cv2.imwrite(file_name, frame)
            
            print(f"--- Đã lưu bằng chứng: {file_name} ---")
            last_saved_time = current_time # Cập nhật thời điểm chụp cuối

    cv2.imshow('AI Evidence Collector', results[0].plot())

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

2. Tương Tác Giác Quan: Điều Khiển Âm Lượng Bằng Cử Chỉ Tay

Khác với sự tĩnh lặng của dữ liệu tài chính, dự án này ngập tràn tính tương tác. Tôi đã ứng dụng Trí tuệ nhân tạo thời gian thực (Real-time AI) để biến camera laptop thành một cảm biến, trực tiếp can thiệp vào phần cứng máy tính.

Thành quả: Tăng giảm âm lượng hệ thống cực mượt chỉ bằng thao tác kéo/thả ngón tay, đi kèm thanh phần trăm và FPS đo thời gian thực.

Cách hệ thống vận hành

  • Sử dụng thư viện OpenCV để bắt trọn từng khung hình từ Webcam liên tục.
  • Nhúng mô hình MediaPipe của Google để dò tìm 21 điểm mốc (landmarks) trên bàn tay.
  • Dùng hàm math.hypot để tính khoảng cách hình học giữa đỉnh ngón cái và ngón trỏ.
  • Ánh xạ toán học np.interp để quy đổi khoảng cách pixel đó sang mức âm lượng và chiều cao của thanh giao diện.
  • Dùng thư viện pycaw (Python Audio Control Wrapper) để móc nối vào hệ thống Windows và chỉnh âm.

Source Code: Gesture Volume Control

Mấu chốt của đoạn script này là sử dụng np.interp để nội suy khoảng cách giữa ngón cái và ngón trỏ (với giới hạn từ 50px đến 200px) sang dải âm lượng thực tế của hệ thống.


import cv2
import mediapipe as mp
import math
import numpy as np
from ctypes import cast, POINTER
from comtypes import CLSCTX_ALL
from pycaw.pycaw import AudioUtilities, IAudioEndpointVolume

# --- 1. SETUP CAMERA & MEDIAPIPE ---
# Dùng cách import chuẩn
mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=1, min_detection_confidence=0.7)
mp_draw = mp.solutions.drawing_utils
cap = cv2.VideoCapture(0)

# --- 2. SETUP ÂM THANH (Bản chuẩn) ---
try:
    devices = AudioUtilities.GetSpeakers()
    interface = devices.Activate(
        IAudioEndpointVolume._iid_, CLSCTX_ALL, None)
    volume = cast(interface, POINTER(IAudioEndpointVolume))
    
    # Lấy dải âm lượng
    vol_range = volume.GetVolumeRange()
    min_vol = vol_range[0]
    max_vol = vol_range[1]
except Exception as e:
    print("Lỗi khởi tạo âm thanh:", e)
    print("Hãy chắc chắn bạn đã chạy lệnh pip install comtypes==1.1.14 pycaw==20181226")
    exit()

# --- 3. VÒNG LẶP CHÍNH ---
while True:
    success, img = cap.read()
    if not success:
        break
        
    img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    results = hands.process(img_rgb)
    
    lm_list = []
    if results.multi_hand_landmarks:
        for hand_lms in results.multi_hand_landmarks:
            mp_draw.draw_landmarks(img, hand_lms, mp_hands.HAND_CONNECTIONS)
            for id, lm in enumerate(hand_lms.landmark):
                h, w, c = img.shape
                cx, cy = int(lm.x * w), int(lm.y * h)
                lm_list.append([id, cx, cy])

    if len(lm_list) != 0:
        # Lấy tọa độ ngón cái (4) và ngón trỏ (8)
        x1, y1 = lm_list[4][1], lm_list[4][2]
        x2, y2 = lm_list[8][1], lm_list[8][2]
        cx, cy = (x1 + x2) // 2, (y1 + y2) // 2

        # Vẽ hình
        cv2.circle(img, (x1, y1), 15, (255, 0, 255), cv2.FILLED)
        cv2.circle(img, (x2, y2), 15, (255, 0, 255), cv2.FILLED)
        cv2.line(img, (x1, y1), (x2, y2), (255, 0, 255), 3)
        cv2.circle(img, (cx, cy), 15, (255, 0, 255), cv2.FILLED)

        # Tính toán độ dài
        length = math.hypot(x2 - x1, y2 - y1)

        # Chuyển đổi độ dài tay sang âm lượng
        # 50 là chụm tay, 200 là duỗi tay (tùy chỉnh theo khoảng cách cam)
        vol = np.interp(length, [50, 200], [min_vol, max_vol])
        volume.SetMasterVolumeLevel(vol, None)

        if length < 50:
            cv2.circle(img, (cx, cy), 15, (0, 255, 0), cv2.FILLED)

    cv2.imshow("Volume Control", img)
    
    # Nhấn 'q' để thoát
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Những cú "vấp ngã" của dân Dev

Làm việc với hệ thống chưa bao giờ là dễ dàng. Đầu tiên là xung đột thư viện kinh điển giữa `pycaw` và `comtypes` tạo ra các lỗi (NameError, Activate) đỏ lừ terminal. Sau đó là các lỗi thụt lề (IndentationError) đặc trưng của Python khi tôi cố gắng lồng ghép thêm thuật toán tính FPS.

Trải nghiệm người dùng (UX) cũng là một thử thách. Ở bản nháp đầu tiên, âm lượng tăng quá gắt! Tôi nhận ra sự khác biệt giữa thang đo Decibel của Windows (tăng theo hàm Logarit) và cảm nhận âm thanh của tai người (Tuyến tính). Phải điều chỉnh lại thuật toán ánh xạ thì mọi thứ mới "mượt mà" như video trên.

Tổng Kết Hành Trình
