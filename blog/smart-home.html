Building a DIY Smart Home: Sensors, Servos, and Power Struggles

From cardboard prototypes and voltage drops to controlling 220V high-voltage lamps. Here is the unfiltered reality of my Arduino Smart Home project.

Mọi dự án vĩ đại đều bắt đầu từ... những tấm bìa carton. Hôm nay, tôi muốn chia sẻ với các bạn quá trình xây dựng nguyên mẫu Nhà thông minh (Smart Home) của mình bằng Arduino. Không chỉ có những thành công màu hồng, bài viết này còn là nhật ký của những lần mạch chập chờn, lỗi sụt áp, và cách "tư duy kỹ sư" đã giúp tôi khắc phục chúng.

Tổng quan ngôi nhà carton: LCD hiển thị bên ngoài, cảm biến siêu âm quét khoảng cách, servo mở cửa và còi chíp báo động bên trong.

Phần 1: Cánh Cửa Ma Thuật và Cú Lừa Từ Nguồn Điện

Hệ thống tự động đầu tiên tôi muốn làm là một cánh cửa tự động mở ra khi có người bước tới. Ý tưởng khá đơn giản: Sử dụng cảm biến siêu âm để đo khoảng cách, nếu có vật cản lại gần, Arduino sẽ kích hoạt Servo (động cơ bước) kéo cửa ra, đồng thời còi chíp (buzzer) bên trong sẽ kêu lên và màn hình LCD hiển thị thông báo.

Sơ đồ đấu nối hệ thống cảm biến siêu âm, LCD, Còi và Servo với board Arduino.

Thực tế phũ phàng

Tôi tự tin ráp mạch, dùng dây vải nối đầu quay Servo với cánh cửa như hình dưới:

Và đây là kết quả của lần test đầu tiên: Cửa mở lấp lửng do dây bị chùng. Nghiêm trọng hơn, màn hình LCD bị tối đen (sập nguồn), và cảm biến siêu âm liên tục báo khoảng cách bằng 0 dù không có vật cản trước mặt.

Cửa mở lấp lửng, hệ thống mất ổn định do sụt áp nguồn.

Giải quyết Vấn đề 1: Bài toán sụt áp (Voltage Drop)

Sau một hồi "debug", tôi nhận ra vấn đề không nằm ở code. Việc bắt LCD, cảm biến siêu âm và Servo dùng chung một nguồn 5V từ board Arduino đã khiến mạch bị quá tải dòng (đặc biệt là khi Servo bắt đầu quay và hút dòng mạnh). Hệ quả là cảm biến siêu âm bị nhiễu tín hiệu và LCD mất nguồn.

Giải pháp: Tôi quyết định tách nguồn. Tôi sử dụng thêm 2 viên pin Lithium (loại 4.2V và 2000mAh cho mỗi pin) để cấp nguồn riêng biệt, đảm bảo hệ thống điện đủ tải và tín hiệu ổn định tuyệt đối.

Giải quyết Vấn đề 2: Keo nến cứu cánh!

Về phần cơ khí, sợi dây thừng mỏng manh không thể truyền lực đủ tốt. Tôi đã phải nhờ đến "vũ khí tối thượng" của mọi maker: Súng bắn keo nến, để cố định trực tiếp hệ thống truyền động giúp cánh cửa hoạt động trơn tru hơn.

Nâng cấp cơ khí: Dùng keo nến thay thế cho dây truyền động.

Source Code: Smart Door System

Dưới đây là đoạn code điều khiển trung tâm cho toàn bộ hệ thống cửa bảo mật này:


#include <Wire.h> 
#include <LiquidCrystal_I2C.h>
#include <Servo.h>

// Định nghĩa các chân cắm
const int TRIG_PIN = 10;
const int ECHO_PIN = 11;
const int BUZZER_PIN = 8;
const int SERVO_PIN = 9;

// Cấu hình các thông số
const int DISTANCE_THRESHOLD = 20; // Khoảng cách nhận diện (20cm)
bool isDoorOpened = false;         // Biến Cờ

LiquidCrystal_I2C lcd(0x27, 16, 2); 
Servo myservo;

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  
  myservo.attach(SERVO_PIN);
  myservo.write(95); // Vị trí cửa đóng ban đầu

  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("He thong: ON");
}

void loop() {
  if (isDoorOpened == false) {
    
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);
    
    long duration = pulseIn(ECHO_PIN, HIGH);
    long distance = (duration / 2) / 29.1;

    if (distance > 0 && distance <= DISTANCE_THRESHOLD) {
      // Hiển thị LCD
      lcd.clear();
      lcd.setCursor(1, 0);
      lcd.print("WELCOME HOME!");
      
      // Phát tiếng còi
      digitalWrite(BUZZER_PIN, HIGH); delay(150);
      digitalWrite(BUZZER_PIN, LOW); delay(100);
      digitalWrite(BUZZER_PIN, HIGH); delay(150);
      digitalWrite(BUZZER_PIN, LOW);

      // Mở cửa
      for (int pos = 95; pos <= 180; pos++) {
        myservo.write(pos);
        delay(15);
      }

      isDoorOpened = true; 
      lcd.setCursor(0, 1);
      lcd.print("Door: OPENED");
    }
  }
  delay(100); 
}

Phần 2: Điều khiển Bóng đèn thực tế (Hệ thống Relay)

Sau khi xong phần cửa bảo mật, tôi chuyển sang một thử thách thực tế hơn: Điều khiển bóng đèn dân dụng 220V. Dù đây là một module tách rời khỏi ngôi nhà carton, nhưng nó là hệ thống cốt lõi để tôi hiểu cách lập trình can thiệp vào điện lưới.

Bước 1: Tuốt lớp bọc dây điện (tay run run sợ cắt đứt luôn lõi đồng bên trong).
Bước 2: Đấu nối vào đui đèn, nhớ siết ốc vít thật chặt không thì... xẹt điện!
Bước 3: Đui đèn và phích cắm đã sẵn sàng. Nhìn cũng uy tín ra phết!
Bước 4: Cắm điện test thử. Sáng chói loá! (Thở phào nhẹ nhõm vì không nổ cầu chì nhà 😆).

Tích hợp "Trí khôn" bằng Relay & Cảm biến hồng ngoại

Để Arduino (5V) đóng ngắt được dòng 220V, tôi sử dụng một Module Relay. Tôi thiết kế thêm một đèn LED đỏ mắc nối tiếp để test tín hiệu: mỗi khi bấm remote, LED đỏ sẽ nháy trước khi Relay nhảy.

Sơ đồ: Arduino nhận tín hiệu IR, bật LED đỏ, sau đó đóng ngắt Relay để bật đèn.
Bật tắt đèn 220V bằng điều khiển hồng ngoại, thông qua hệ thống Relay.

Source Code: Smart Lamp Control

Đoạn code dưới đây xử lý tín hiệu từ Remote (IR), đồng thời tôi đã tích hợp thuật toán "Chống dội phím" (Debounce) bằng hàm millis() để tránh việc đèn bị bật/tắt liên tục khi vô tình giữ nút quá lâu.


#include <IRremote.hpp>

const int Recv_Pin = 2;
const int Ledpin = 3;

// Biến chống dội (debounce)
unsigned long lastTime = 0;

void setup() {
  Serial.begin(9600);
  pinMode(Ledpin, OUTPUT);
  digitalWrite(Ledpin, LOW); 
  
  IrReceiver.begin(Recv_Pin, true, 8);
  Serial.println("He thong da san sang...");
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t dataRemote = IrReceiver.decodedIRData.decodedRawData; 
    
    if (dataRemote > 0) {
      Serial.print("Ma nhan duoc: ");
      Serial.println(dataRemote);
      
      // Chống dội: chỉ xử lý nếu lần bấm cách nhau > 250ms
      if (millis() - lastTime > 250) {
        switch(dataRemote) {
          case 4077715200UL: // Nút Toggle
            digitalWrite(Ledpin, !digitalWrite(Ledpin));
            Serial.println("Nut 1: Dao trang thai den");
            break;
          
          case 3877175040UL: // Nút Chớp tắt
            digitalWrite(Ledpin, LOW);
            delay(500);
            digitalWrite(Ledpin, HIGH);
            Serial.println("Nut 2: Chop tat den");
            break;
            
          default:
            Serial.println("Nut nay chua thiet lap.");
            break;
        }
      }
      lastTime = millis();
    }
    IrReceiver.resume(); 
  }
}
